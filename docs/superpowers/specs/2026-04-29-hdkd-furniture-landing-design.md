# HDKD 가구 랜딩 페이지 설계

**날짜:** 2026-04-29  
**목적:** flexmstudio.com 포트폴리오 안에 HDKD 가구회사 리뉴얼 샘플 추가 (취업 포트폴리오용)  
**라우트:** `/hdkd`

---

## 목표

- 기존 hdkd.co.kr 사이트를 현대적으로 리뉴얼한 샘플 랜딩 페이지
- "이 정도 만들 수 있다"를 보여주는 포트폴리오 목적
- 실제 가구회사 웹관리자 면접 시 차별화 포인트로 활용

---

## 기술 스택

- React 18 + TypeScript + Vite (기존 프로젝트 동일)
- Tailwind CSS v4
- `motion/react` (Framer Motion) — 스크롤 애니메이션
- `lucide-react` — 아이콘
- Layout 컴포넌트 없이 독립 페이지 (NukkiAI와 동일 방식)

## 페이지 구조

### 1. 헤더 (Header)
- 로고 텍스트 "HDKD" + 브랜드명
- 네비게이션: 제품, 회사소개, 문의
- 스크롤 시 배경 생김 (backdrop-blur)
- 모바일: 햄버거 메뉴

### 2. 히어로 (Hero)
- 풀 뷰포트 높이
- 배경: 따뜻한 그라디언트 + 우드 텍스처 느낌 오버레이
- 메인 슬로건: "자연에서 온 가구, 삶에 스며들다"
- 서브: "국내 장인이 직접 제작하는 원목 가구"
- CTA 버튼: "제품 보기" (포인트 색상)
- 스크롤 다운 화살표 애니메이션

### 3. 특징 (Features)
- 3개 카드 그리드
- 카드 1: 자체 제작 (직접 만든다는 강점)
- 카드 2: 천연 원목 소재
- 카드 3: A/S 보장
- 스크롤 페이드인 애니메이션

### 4. 제품 갤러리 (Products)
- 2×3 또는 3×2 그리드
- 더미 이미지: Unsplash 가구 이미지 URL
- 카드: 제품명 + 간단 설명 + 호버 시 확대 효과
- 제품 종류: 소파, 식탁, 침대, 수납장, 의자, 책상

### 5. 회사소개 (About)
- 좌: 텍스트 (설립 연도, 브랜드 스토리 2~3줄)
- 우: 수치 카운트업 3개
  - 설립 15년
  - 제품 200+개
  - 고객 5,000+명
- `useCountUp` 훅 활용 (기존 코드)

### 6. 문의 (Contact)
- 이름, 연락처, 문의 내용 입력 폼
- Web3Forms 연동 (기존 Contact 페이지 방식)
- 제출 버튼 (포인트 색상)

### 7. 푸터 (Footer)
- 회사명, 주소, 대표 전화
- 인스타그램 링크
