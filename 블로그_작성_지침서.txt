────────────────────────────────────────────────────────────────
1. 기본 규칙
────────────────────────────────────────────────────────────────

- 출력 형식: 완전한 HTML 파일 (<!DOCTYPE html> ~ </html>)
- 파일명 규칙: [주제]_v1.html (버전 번호 붙일 것)
- 폰트: 'Paperlogy', 'Pretendard', sans-serif
- 다크/라이트 모드: prefers-color-scheme 미디어쿼리로 자동 전환
- 언어: 한국어, word-break: keep-all 적용
- 최대 너비: 780px, 가운데 정렬
- CSS는 <style> 태그 내 인라인으로 전부 포함 (외부 파일 없음)


────────────────────────────────────────────────────────────────

────────────────────────────────────────────────────────────────
3. HTML 파일 기본 구조 (템플릿)
────────────────────────────────────────────────────────────────

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>[글 제목]</title>
  <meta name="description" content="[검색 설명 1~2줄]" />
  <meta name="keywords" content="[태그1, 태그2, ...]" />
  <style>
    /* ── 디자인 토큰 ── */
    :root { ... }
    @media (prefers-color-scheme: dark) { :root { ... } }

    * { box-sizing: border-box; margin: 0; padding: 0; }
    body { font-family: 'Paperlogy', 'Pretendard', sans-serif; background: var(--c-bg); color: var(--c-text); line-height: 1.75; word-break: keep-all; font-size: 1rem; }

    .wrap { max-width: 780px; margin: 0 auto; padding: 3.5rem 1.5rem 5rem; }

    /* ── 각 컴포넌트 스타일 ── */
    ...

    @media (max-width: 600px) {
      h1 { font-size: 1.4rem; }
      h2 { font-size: 1.2rem; }
      .wrap { padding: 2rem 1rem 3rem; }
    }
  </style>
</head>
<body>
<div class="wrap">
  [① 헤더]
  [② 도입부 본문]
  [③ 목차]
  [④ 섹션들 (h2 + 내용)]
  [⑤ FAQ (있을 경우)]
  [⑥ 마무리]
  [⑦ 태그]
</div>
</body>
</html>

4. 컴포넌트별 HTML 코드
────────────────────────────────────────────────────────────────

【① 헤더 영역】
─────────────────────────────────────────────
<header class="post-header">
  <span class="post-label">[카테고리명]</span>
  <h1>[글 제목]</h1>
  <p class="post-lead">[리드 문장 — 독자 흥미 유발, 1~2문장]</p>
  <div class="accent-bar"></div>
  <div class="post-meta">
    <span>✦ [기준년도]년 기준</span>
    <span>· 읽는 시간 약 [N]분</span>
  </div>
</header>

.post-header { margin-bottom: 2.5rem; }
.post-label { display: inline-block; font-size: 0.72rem; font-weight: 700; letter-spacing: 0.08em; text-transform: uppercase; color: var(--c-accent); background: color-mix(in srgb, var(--c-accent) 10%, transparent); border: 1px solid color-mix(in srgb, var(--c-accent) 25%, transparent); border-radius: 999px; padding: 0.25rem 0.75rem; margin-bottom: 1rem; }

────────────────────────────────────────────────────────────────
5. 글쓰기 스타일 가이드
────────────────────────────────────────────────────────────────

톤앤매너:
  - 1인칭 구어체 ("저는", "저도", "~더라고요", "~거든요")
  - 딱딱하지 않게, 친근하지만 신뢰감 있게
  - 개인 경험/사례 1~2개 포함
  - 이모지는 섹션 제목과 박스 라벨에만 제한적으로 사용

구조:
  - 헤더 → 도입부 (2~3문단) → 목차 → 본문 섹션 4~6개 → FAQ (5~6개) → 마무리 → 태그
  - H2 섹션마다 본문 + 컴포넌트(테이블/리스트/박스) 1개 이상 포함
  - 각 섹션은 700~1000자 내외

SEO:
  - <title>에 핵심 키워드 + 연도 포함
  - <meta description> 80~120자
  - H1은 1개, H2는 4~7개
