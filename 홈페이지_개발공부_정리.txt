[ Flexbox ]
  display: flex           → 가로/세로 방향으로 요소 배치
  align-items: center     → 수직 가운데 정렬
  justify-content: center → 수평 가운데 정렬
  gap: 1rem               → 아이템 사이 간격
  flex-wrap: wrap         → 넘치면 다음 줄로 이동
  flex: 1                 → 남은 공간을 채움

[ CSS Grid ]
  display: grid
  gridTemplateColumns: repeat(auto-fill, minmax(240px, 1fr))
  → 카드가 최소 240px 유지하면서 화면 너비에 따라 자동으로 열 수 조절
  → "auto-fill"은 공간이 있으면 계속 열 추가, "1fr"은 남은 공간 균등 분배

[ 반응형 - clamp() ]
  fontSize: 'clamp(1rem, 2.5vw, 1.3rem)'
  → 최솟값, 가변값, 최댓값을 한 번에 지정
  → 화면이 작으면 1rem, 커지면 2.5vw, 최대 1.3rem
  → media query 없이 반응형 폰트 크기 구현

[ position 활용 ]
  position: fixed         → 스크롤해도 화면에 고정 (헤더, 모달 오버레이)
  position: absolute      → 부모 기준으로 자유롭게 위치 지정
  position: relative      → absolute 자식의 기준점이 됨
  inset: 0                → top/right/bottom/left 모두 0 (화면 꽉 채움)
  zIndex                  → 요소 앞뒤 순서 (숫자 클수록 앞)

5. 애니메이션 기법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[ CSS Keyframe 애니메이션 ]
  사이트에 사용된 종류:

  fadeInUp    : 아래에서 위로 페이드인 (페이지 첫 로딩)
  fadeIn      : 투명→불투명 (모달 배경)
  modalIn     : 살짝 작아진 상태에서 커지며 나타남 (모달 창)
  float       : 위아래로 둥둥 떠다님 (배경 오브, 스크롤 화살표)
  floatB      : float의 변형 버전
  shimmer     : 좌→우로 빛이 흐르는 효과 (FlexM 텍스트)
  blink       : 깜빡임 (타이핑 커서)
  pulse-glow  : 빛이 커졌다 작아졌다 반복 (환영 뱃지 점)

  작성법:
  @keyframes float {
    0%, 100% { transform: translateY(0) }
    50%      { transform: translateY(-22px) }
  }
  → 0%는 시작, 50%는 중간, 100%는 끝 상태

[ transition ]
  transition: all 0.2s ease
  → 속성이 바뀔 때 0.2초 동안 부드럽게 변함
  → hover 효과에 주로 사용

[ transform ]
  translateY(-6px)      : 위로 6px 이동 (hover 시 카드가 떠오르는 느낌)
  scale(1.01)           : 1% 확대
  perspective(900px)    : 3D 원근감 설정
  rotateY(14deg)        : Y축으로 기울임 (TiltCard 효과)

[ will-change: transform ]
  → 브라우저에게 "이 요소는 transform이 자주 바뀔 거야"라고 미리 알려줌
  → GPU 레이어에 올려서 애니메이션이 더 부드럽게 렌더링됨

[ ParticleCanvas - 네트워크 파티클 애니메이션 ]
  - HTML5 <canvas> 태그에 JavaScript로 직접 점과 선을 그림
  - 120개의 점(Dot)이 랜덤 방향으로 천천히 이동
  - 두 점 사이 거리가 180px 이내면 선으로 연결
  - requestAnimationFrame으로 매 프레임 다시 그림 (보통 초당 60회)
  - resize 이벤트: 화면 크기 바뀌면 캔버스 크기도 자동 조절

  핵심 원리:
  거리 계산: dist = Math.sqrt(dx*dx + dy*dy)  ← 피타고라스 정리
  투명도:    opacity = 1 - dist/180  ← 멀수록 선이 흐려짐

[ TiltCard - 마우스 따라 기울어지는 카드 ]
  - onMouseMove 이벤트로 마우스 위치를 감지
  - 카드 내 마우스 상대 좌표를 -0.5 ~ 0.5 범위로 정규화
  - CSS perspective + rotateX/rotateY로 3D 기울기 표현
  - 마우스 위치에 shine(빛 반사) 효과 추가
  - onMouseLeave 시 원래 상태로 복귀

[ CursorGlow - 마우스 커서 따라다니는 빛 ]
  - mousemove 이벤트로 마우스 좌표를 실시간으로 받아서
    div의 left/top을 업데이트
  - 600px 크기의 반투명 파란 원이 커서 중심으로 따라다님
  - transition: 0.08s 로 살짝 느리게 따라와서 부드러운 느낌

[ TypingText - 타이핑 효과 텍스트 ]
  - useState로 현재 표시 중인 텍스트, 삭제 중 여부, 문구 인덱스 관리
  - useEffect + setTimeout으로 글자를 하나씩 추가/삭제
    · 타이핑: 85ms마다 글자 하나 추가
    · 삭제:  45ms마다 글자 하나 제거 (더 빠르게)
    · 완성 후 2초 대기, 삭제 시작, 다음 문구로
  - 깜빡이는 커서는 CSS animation으로 구현

[ useCountUp - 숫자 카운트업 훅 ]
  - IntersectionObserver: 요소가 화면에 보이기 시작하는 순간 감지
  - 보이는 순간 숫자가 0 → 목표값까지 올라감
  - easing 함수: 1 - Math.pow(1-progress, 3) → 처음엔 빠르게, 나중엔 느리게

[ useScrollFadeIn - 스크롤 페이드인 훅 ]
  - IntersectionObserver로 요소가 15% 이상 보이면
  - is-visible 클래스를 추가 → CSS transition으로 페이드인

[ Glassmorphism (유리 효과) ]
  backdrop-filter: blur(24px) saturate(1.4)
  → 뒤 배경을 뿌옇게 흐림 + 채도 증가
  → 반투명 유리처럼 보이는 효과
  background: rgba(255,255,255,0.7) 와 함께 사용

[ Gradient Border (그라디언트 테두리) ]
  .glow-card::before 의 기법:
  - padding이 있는 가상요소(::before)에 그라디언트 배경 적용
  - -webkit-mask + mask-composite: exclude 로 테두리만 남김
  → 일반 border로는 불가능한 그라디언트 테두리를 구현하는 CSS 트릭

[ Radial Gradient Orb (배경 빛망울) ]
  background: radial-gradient(circle, rgba(40,96,255,0.10) 0%, transparent 70%)
  → 중심은 색이 있고 바깥으로 갈수록 투명해지는 원형 그라디언트
  → filter: blur(50px) 로 퍼지게 만들어 배경 분위기 조성

[ Shimmer Text (빛이 흐르는 텍스트) ]
  background: linear-gradient(90deg, 색1 0%, 색2 30%, 색3 60%, 색1 100%)
  background-size: 200% auto
  -webkit-background-clip: text
  -webkit-text-fill-color: transparent
  animation: shimmer (background-position 이동)
  → 텍스트 모양대로 배경이 잘려 보이면서 그라디언트가 좌우로 흐름

[ color-mix() ]
  color-mix(in srgb, var(--c-accent) 10%, transparent)
  → CSS 함수로 두 색상을 섞음
  → 예: 파란색 10% + 투명 90% = 매우 연한 파란색
  → rgba(r,g,b,a) 대신 현재 테마 색상 변수를 그대로 활용 가능

[ box-shadow 레이어링 ]
  box-shadow를 여러 개 쌓아서 입체감 표현:
  0 1px 0 rgba(255,255,255,0.06) inset  ← 상단 내부 하이라이트
  0 4px 16px var(--c-card-shadow)       ← 아래 그림자
  0 0 40px color-mix(...)               ← 바깥으로 번지는 글로우

[ backdrop-filter ]
  backdrop-filter: blur(8px)
  → 해당 요소 뒤의 콘텐츠를 흐리게
  → 헤더, 카드, 뱃지 등에 유리 느낌 부여
  ※ Safari는 -webkit-backdrop-filter 필요

8. React 핵심 개념 (사이트에서 사용된 것만)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[ useState ]
  const [count, setCount] = useState(0)
  → 값이 바뀌면 화면을 다시 렌더링
  → 타이핑 텍스트, 다크모드 토글 등에 사용

[ useEffect ]
  useEffect(() => { ... }, [의존성])
  → 컴포넌트가 렌더링된 후 실행
  → 이벤트 리스너 등록, API 호출, 타이머 설정에 사용
  → return에 cleanup 함수를 넣으면 컴포넌트 사라질 때 정리

[ useRef ]
  const ref = useRef<HTMLDivElement>(null)
  → DOM 요소에 직접 접근할 때 사용
  → 값이 바뀌어도 리렌더링을 일으키지 않음
  → canvas 조작, 스크롤 위치 감지 등에 사용

[ Custom Hook (커스텀 훅) ]
  use로 시작하는 함수로 로직을 재사용 가능하게 분리
  useCountUp, useScrollFadeIn, useMetaTags 등
  → 여러 컴포넌트에서 같은 로직을 반복 작성하지 않아도 됨

[ Context API ]
  createContext, useContext
  → props를 여러 단계 거치지 않고 어디서든 데이터 접근
  → 이 사이트에서는 다크모드(ThemeContext), 관리자 여부(AdminContext)에 사용

  → 요소가 화면 안에 들어오는 순간을 감지하는 API
  → 스크롤 애니메이션, 카운트업에 활용
  → 기존 scroll 이벤트보다 성능이 훨씬 좋음

[ requestAnimationFrame (rAF) ]
  → 브라우저 화면 갱신 주기(보통 60fps)에 맞춰 함수를 호출
  → 파티클 캔버스 애니메이션, 카운트업에 사용
  → setTimeout 대비 훨씬 부드러운 애니메이션 가능

[ Canvas API ]
  → <canvas> 태그에 자바스크립트로 직접 그래픽을 그림
  → ctx.beginPath(), ctx.arc(), ctx.stroke(), ctx.fill() 등
  → 파티클 네트워크 애니메이션에 사용

[ localStorage ]
  → 브라우저에 데이터를 저장하는 API
  → 다크모드 설정, 관리자 로그인 상태 유지에 사용
  → 새로고침해도 사라지지 않음
